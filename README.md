# ObjectDetectionPro

Real-time object detection system built using SSD-MobileNetV2 
pretrained on COCO dataset, fine-tuned on Kaggle Open Images V7.

## About
This project detects everyday objects like people, cars, dogs, 
chairs, and books in real-time using a single image or webcam feed.

## Tech Stack
- Python 3.10
- TensorFlow 2.13
- OpenCV 4.8
- Kaggle Open Images V7 Dataset

## Model Architecture
- Base Model  : SSD (Single Shot MultiBox Detector)
- Backbone    : MobileNetV2 (pretrained on ImageNet)
- Trained on  : COCO Dataset (80 classes)
- Fine-tuned  : Kaggle Open Images V7 (600+ classes)
